# SRS-002：巨集錄製與書籤

| 項目 | 內容 |
|---|---|
| 版本 | 1.0 |
| 狀態 | 已拍板，開發中 |
| 前置 | SRS-001（欄模式編輯器核心，已完成） |
| 範圍 | 本期 MVP 全做完；無後期 Phase 延後項 |

## 1. 背景

SRS-001 收尾時列出 Notepad++ 有而本編輯器尚缺的功能：巨集錄製、檔案比對、
外掛系統、書籤、程式碼摺疊、工作階段還原。本期取其中兩項——巨集與書籤——
它們共用「對文件做重複性批次操作」這個使用情境，一起做綜效最高。

## 2. 拍板決策

| 編號 | 決策 | 理由 |
|---|---|---|
| **D-01** | 巨集錄製在「語意命令層」，不錄原始鍵盤事件 | 原始事件重播會受焦點、輸入法組字狀態、視窗大小影響而不可靠；語意命令可序列化、可存檔、可跨 session 重播，也才能正確重播欄模式操作 |
| **D-02** | 連續文字輸入合併成單一步驟 | 打 10 個字不該產生 10 個步驟；巨集要可讀、重播要快 |
| **D-03** | 書籤以獨立的「行號集合」保存，文件變動時平移 | `QTextBlock.userState` 已被語法上色的區塊註解狀態佔用；`QTextBlockUserData` 在 undo 後會失效。獨立集合可單元測試 |
| **D-04** | 巨集存成 JSON 於 `~/.config/StephanyEditor/macros.json` | 人類可讀、可手改、可版控、可在機器間搬移 |
| **D-05** | 重播時任一步驟失敗即停止並回報，不續跑剩餘步驟 | 失敗後續跑會在錯誤位置做出破壞性編輯，比停下來更糟 |
| **D-06** | 書籤為每個分頁獨立，不隨檔案存檔 | 書籤是暫時性的工作標記；要持久化屬於「工作階段還原」功能的範圍，不在本期 |

## 4. 業務規則

### 書籤

| 編號 | 規則 |
|---|---|
| **BR-BM-1** | 在書籤上方插入或刪除行時，書籤必須跟著平移，保持貼在原本那一行內容上 |
| **BR-BM-2** | 被刪除的那一行上的書籤一併移除 |
| **BR-BM-3** | 跳轉為繞回式（wrap around）：最後一個書籤按 `F2` 回到第一個 |
| **BR-BM-4** | 沒有任何書籤時 `F2` / `Shift`+`F2` 無動作，狀態列提示 |
| **BR-BM-5** | 書籤行號超出文件範圍時（外部縮短文件）自動丟棄 |

### 巨集

| 編號 | 規則 |
|---|---|
| **BR-MC-1** | 連續的文字輸入步驟合併為一個（對應 D-02） |
| **BR-MC-2** | 一次重播（含多次播放的全部迭代）包在單一 undo 區塊，一次 `Ctrl`+`Z` 還原 |
| **BR-MC-3** | 「直到檔尾」模式的停止條件：游標到達文件結尾、或一次迭代後游標位置與文件長度都沒變（偵測空轉），且有最大迭代次數上限防止無窮迴圈 |
| **BR-MC-4** | 重播中步驟失敗即停止並回報失敗的步驟（對應 D-05） |
| **BR-MC-5** | 不可同時錄製與播放；錄製中播放請求應被拒絕 |
| **BR-MC-6** | 欄模式的步驟以「相對位移」記錄，不記絕對座標，重播才能套用到不同位置 |

## 5. 非功能需求

| 編號 | 需求 |
|---|---|
| NF-01 | 書籤平移運算為純函式，不依賴 Qt，可單元測試 |
| NF-02 | 巨集步驟序列化格式為 JSON，欄位名稱自我描述，可手動編輯 |
| NF-03 | 載入損毀的 macros.json 不得導致程式無法啟動，應退回空清單並提示 |
| NF-04 | 書籤數量達數千個時跳轉仍須即時（使用排序後二分搜尋，不做線性掃描） |
